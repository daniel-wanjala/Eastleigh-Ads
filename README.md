# Eastleigh E-commerce Ads

A mobile-first landing page for Eastleigh E-commerce Ads, focused on Meta advertising setup for Kenyan e-commerce businesses.

## Current offer

- **One-time setup fee:** KSh 20,000.
- **Ongoing management:** optional and priced separately based on scope.
- **Advertising spend:** paid separately by the client to Meta from the client's own ad account.
- **Primary conversion path:** WhatsApp inquiry.

The site intentionally avoids promising guaranteed sales. Its case-study section reports campaign activity (messaging conversations, reach, clicks and CTR) and clearly notes that conversations are not confirmed sales.

## Stack

- HTML5, CSS3 and vanilla JavaScript
- Node.js and Express
- Vercel deployment configuration
- GitHub version control

## Local development

Requirements: Node.js 18+ and npm.

```bash
git clone https://github.com/daniel-wanjala/Eastleigh-Ads.git
cd Eastleigh-Ads
npm install
npm start
```

Open http://localhost:3000 in your browser.

## Deployment

The repository is configured for Vercel. Review changes in a pull request before merging to `main`; merging to the production branch may trigger deployment depending on the Vercel project settings.

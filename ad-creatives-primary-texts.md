## Suggested First Test

With a limited daily budget, don't launch all ten variations at once. Start with a small number of ads so each gets enough spend to produce useful signals.

- **Homepage campaign:** Creative 4 — Reach Customers Where They Are.
- **Direct application campaign:** Direct Application 3 — All Packages.
- **Video creative:** Use the pricing message from Creative 5, with regional, nationwide and custom-quote options appearing sequentially.

Review actual results before deciding which copy to scale. Avoid promising specific sales or results that have not been verified.
